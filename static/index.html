This is the format the AI writes. Edit it by hand and apply, or copy it somewhere else. Drum strings use . rest, x hit, X accent, g ghost, 2 3 4 6 8 rolls. With several pages, drum strings get one 16-step chunk per page separated by |. Synth steps use a note like "F#2", "-" to hold, "." to rest. On a "poly": true channel a step can be a chord, notes joined by + like "C3+E3+G3".
